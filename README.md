#  Protein Calculator & Tracker

A simple web application that calculates a user's daily protein needs and helps track daily protein intake.

## Features

* Calculate daily protein requirements based on:

* Age
* Weight
* Fitness goal
* Training frequency
  
* Save user data using LocalStorage
* Track daily protein consumption by date
* View protein intake history in a calendar-style page
* Store protein logs in Supabase

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage
* Supabase

## How It Works

1. Enter your personal information.
2. Calculate your daily protein target.
3. Add consumed protein amounts each day.
4. Monitor your progress and compare it with your target.

## Project Structure

